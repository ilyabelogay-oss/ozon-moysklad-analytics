# Ozon + МойСклад — аналитика прибыльности

Полноценное Streamlit-приложение.

## Что делает
- Тянет выручку и заказы с Ozon (analytics)
- Достаёт артикул (offer_id) по SKU
- Тянет себестоимость из МоегоСклада только по коду товара
- Матчит: артикул Озона = код в МС
- Берёт баллы за скидки из realization
- Показывает грубую прибыль (выручка − себестоимость)
- Экспорт в CSV

## Запуск
```bash
pip install -r requirements.txt
streamlit run ozon_moysklad_analytics.py
```

## Ключи
- Ozon: Client-Id + Api-Key (кабинет продавца → Настройки → API)
- МойСклад: Access Token (Настройки → Токены)

## Ограничения
- `/v3/finance/transaction/list` отключён с июля 2026 — расходы могут не прийти
- Баллы берутся из realization за месяц
- Комиссии/логистика не раскиданы по каждому SKU (нужна отдельная логика по операциям)
- Пагинация ограничена
